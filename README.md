# AMax Web

This is not the source code, this is a mod for the compiled version.


## Features

- copied completely (without source code)
- Analytics removed
- Server set to 127.0.0.1
- Added the ability to change some text on the login page

To change any value, edit config.js file

## Installation

Nginx is required for correct operation.

```bash
sudo apt install nginx -y
```
After that, download the repo and move it in /var/www/html
